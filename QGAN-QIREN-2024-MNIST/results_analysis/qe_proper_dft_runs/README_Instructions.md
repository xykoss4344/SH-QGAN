# Quantum ESPRESSO Run Instructions
This directory contains the ready-to-run Quantum ESPRESSO (`pw.x`) inputs for the top 5 Mg-Mn-O crystal structures generated by our Quantum GAN (QGAN-v4) model.

## Directory Structure
- `crystal_rank01` to `crystal_rank05`: The DFT run directories for the 5 structures.
- `pseudo/`: Contains the optimized `.UPF` pseudopotentials exactly as required by the `.in` scripts.

⚠️ **Note:** If you see any empty `out` subdirectories, it simply means that step has not been calculated yet. The input files (`.in`) themselves are fully populated with cell parameters, K-points, and atomic positions.

## Execution Sequence
For each `crystal_rank` directory, there is a two-step sequence:

### Step 1: PBE+U Geometric Relaxation
1. `cd` into `crystal_rankXX/step1_pbe_u_relax/`
2. Run the relaxation script using your cluster's MPI executor. For example:
   ```bash
   mpirun -np <cores> pw.x -in pw_relax.in > pw_relax.out
   ```
*(Note: Be sure your job-runner environment resolves the `pseudo_dir` parameter properly. It is configured to point relatively to `../../pseudo/`).*

### Step 2: HSE06 Static Hybrid Calculation
Since Step 1 will change the atomic coordinates from relaxation, you must pipe the newly relaxed coordinates into Step 2 before running it.
1. `cd` into `crystal_rankXX/step2_hse_static/`
2. Open your successfully finished `pw_relax.out` from Step 1, copy the new final `ATOMIC_POSITIONS`, and paste them into `pw_hse_static.in` (overwriting the unrelaxed template coordinates).
3. Run the heavy static execution:
   ```bash
   mpirun -np <cores> pw.x -in pw_hse_static.in > pw_hse_static.out
   ```
